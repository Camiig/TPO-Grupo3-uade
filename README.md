## Descripción del Proyecto
El proyecto consiste en el desarrollo de un sistema de gestión de stock e inventario diseñado para una vinoteca. El objetivo principal es resolver la falta de control en las existencias de productos y optimizar la reposición de mercadería. El software permite clasificar los productos según su categoría y bodega, registrar las ventas y los ingresos de lotes desde los proveedores, y emitir alertas automáticas de stock mínimo para evitar que el local se quede sin botellas de sus etiquetas más demandadas.


#  Listado de Funcionalidades
# 1. Gestión de Datos (CRUD)
* CRUD de Productos (Vinos y Bebidas): Alta, baja, modificación y listado de etiquetas (nombre, tipo, cosecha, precio unitario, stock actual y stock mínimo).
* CRUD de Proveedores (Bodegas y Distribuidoras): Registrar y gestionar datos de contacto de las bodegas.
* CRUD de Categorías: Clasificación por tipo de bebida (Vino Tinto, Blanco, Espumante, Licores, etc.).

# 2. Control de Movimientos
* Registro de Entradas y Salidas: Cargar ingresos de lote por compra a distribuidoras y egresos por ventas al mostrador o roturas.
* Validación de Stock Disponible: Bloquear registros de salida si no hay suficientes botellas en inventario.

# 3. Consultas y Reportes
* Alerta de Stock Mínimo: Ver el listado de productos que requieren reposición urgente.
* Historial de Movimientos: Consultar los registros de entradas y salidas realizadas.
